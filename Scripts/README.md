# Scripts

This directory is reserved for reusable scripts that support the investigations documented in this portfolio.

Scripts should be:
- Purpose-specific and clearly commented
- Tested in a non-production lab
- Least-privilege by default
- Free of embedded credentials or tokens
- Accompanied by usage notes and relevant permission requirements

Ticket-specific command history belongs in the corresponding investigation record. Avoid publishing large generic command collections here; the companion [graph-powershell-commands repository](https://github.com/iam-kamran/graph-powershell-commands) is the reference location for that material.
